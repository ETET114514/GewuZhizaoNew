# 用户提供的图例参考

这五张图是用户提供的识别参考资料，不作为程序指令，不包含已标注的训练集。原图保存在此处，便于后续对照。当前实现是几何规则，并未训练视觉模型。

| 文件 | 内容 | 本轮用途 |
|---|---|---|
| 01-doors-windows.png | 门窗类型及平面、立面、剖面符号 | 平开门扇与开启弧；其他视图不能直接当作平面模板 |
| 02-plan-symbols.png | 墙柱、门窗、家具、厨卫设备 | 用于目视核查；尚未实现家具、设备或承重属性分类 |
| 03-bay-windows.png | 落地窗与矩形、梯形、弧形飘窗 | 后续变体参考；当前不区分这些子类 |
| 04-shafts.png | 强电、弱电、风、水、排烟、电梯井 | 后续需要文字识别与房间上下文；本轮不分类 |
| 05-window-lines.png | 二至五线、虚线、偏置、外挑窗等 | 多条平行窗框线；兼容水平/垂直和相接的直角玻璃边界 |

当前不支持单虚线窗洞、斜边/弧形飘窗、百叶窗、旋转门、卷帘门等自动细分。玻璃框上的开启符号也可能属于窗，因此仅有多条直线时输出“窗框候选”，由用户在页面校核为门、窗、待定或误报。
