图二、三、五属于同一户型组，不作为三个独立测试户型。原图中的承重/剪力墙说明只用于理解该图，不能推广为“所有深灰色墙都是承重墙”。

## 规则变化

- 保留深色实墙检测，并恢复因交接处宽度变化而被整体过滤的局部实墙带。
- 双线墙要求局部成对边缘、厚度与连续性、端帽或墙网连接证据。仅在两侧边线均有像素支撑时跨越短交叉线，不跨空白门洞补墙。
- 密集图采用较强的边缘对比和更保守的墙网筛选，避免把家具、尺寸线大量纳入墙体。
- 窗候选先扣除已恢复的双线墙范围，避免窗框线跨过相邻墙段。
- 多线闭合外框同时可能是窗、栏杆或设备。此类候选带 `requires_confirmation: true`，显示为边界待确认；人工确认为门/窗之前，不生成连接或扣除实墙。
- 人工改为“类别待定”也停止扣墙。确认、排除、编辑、保存和撤销沿用同一套派生实墙计算。

## 验证与仍有的缺口

`landmarks.json` 保存人工选取的墙体与非墙位置。共 48 个墙体点、38 个非墙点，属于稀疏核查，不是完整分割标注，不能据此宣称整图准确率。

当前六张图的墙体点命中分别为 **10/10、10/10、10/10、7/7、4/6、5/5**，38 个非墙点均保持非墙。图五 `(602,585)` 和 `(693,660)` 的短隔墙仍漏检，明确记录在 `known_missed_walls`；回归测试不会将其伪装为已通过的墙体点。

部分墙角、短墙端帽尚不完整，门窗与设备、栏杆仍可能有漏检或类别歧义。没有自动学习房间语义、识别全部图例、推断承重属性或读取真实比例。

复现：

```powershell
python evaluate_reference_plans.py
python -m unittest discover -s . -p "test_*.py" -v
```
