## 当前识别实现

`templates.json` 明确列出 11 个裁切框与类别，不包括图例下方类别文字。`head_rotation_deg` 表示原裁切中床头/靠背方向，程序将其转成上方再进行旋转和镜像匹配。06 的裁切仍含穿过家具的部分引线，匹配能力受这种画法影响。

图例只是显式模板，没有训练模型权重、读取 OCR、推断房间功能，也没有按目标图片文件名、哈希或固定位置输出家具。

先将待识别图最长边限制到 1000 像素，再做局部对比处理、尺度搜索、四个正交朝向与镜像匹配；模板尺寸步长约 6%。床短边至少 40 像素、沙发短边至少 28 像素（均指缩小后的图）。过小符号会因细节不足而跳过。初始阈值：床 0.86、沙发 0.78，都是相关性分数，不是准确率或概率。

平坦区域在寻找峰值前排除，避免零方差使相关性分数失真；重叠候选做去重。尚不处理任意角度、复杂组合沙发、任意画法或通用家具分类。低清、标注遮挡和未收录符号可能漏检或误报。
