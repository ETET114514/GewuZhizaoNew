## 实现边界

- 共线墙端只在轴线接近且厚度兼容时连接；L/T 交接沿原墙方向延至交点，不移动原墙。
- 连接距离上限为较小墙厚的 3 倍，且不超过按图幅缩放的 40 px。无像素证据只允许不超过墙厚 0.6 倍、缩放后 8 px 的小缝。
- 更长补接要求至少 75% 的纵向采样有实心墙或双边轮廓支撑；单条线不能单独支撑补墙。最近连接优先，同一轮避免同一个墙端向多个目标重复连接。
- 新增区域与任何未排除门窗、待确认边界或手工洞口相交时不补接，包括垂直相交的洞口。之后重新计算实墙，三维沿用修复墙段及原洞口约束。
- 浅色图的大段外围边界、圆角、没有墙线证据的长缺口仍未闭合。旧识别的家具误报仍可能成为错误连接的依据；橙色补接需校核。尚无房间轮廓重建或网格布尔合并。

## 复现与验证

在 `wall-recognition` 目录执行 `python evaluate_connections.py` 生成三图对比，并验证重复执行不改变墙体几何。新增单元测试覆盖共线补接、L/T 交接、原墙不移动、缩放和旋转、空白长缺口、错位平行墙、双线与实心墙证据、门窗/待确认/手工洞口保护、重复点击及删除后不自动复生。接口测试检查连接、保存的二维实墙和撤销；三维测试检查补接墙生成且门窗仍透空。
