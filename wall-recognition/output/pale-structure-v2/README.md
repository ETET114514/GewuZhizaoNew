## 工作台操作

- 展开“识别设置 · 同图多种墙色”，添加或在原图上取色，最多六种，容差 1–24。重新识别后生效；新图清空旧颜色，保存项目保留实际使用的参数。包含白底的过亮颜色范围会被拒绝。
- 外围边界初始不作为实墙、不切割墙体。可在校核类别里“确认为墙”，生成可编辑墙段；改回窗、门或待定时撤回对应确认墙。支持撤销。
- 中央灰色区域可改为“水景 / 水池”，或继续保留“区域待确认”。可修改框、排除或撤销。

## 已知缺口

外围圆角和底部部分短边界没有补全。部分厨房入口、左下套间附近的门仍缺少可用墙端支撑，未自动补出。原有深色分支仍会将某些柜内深色块、水槽或浴缸内部当墙。浅色边界无法仅凭颜色判断实体墙或玻璃，线段宽度也只是候选估计。

柜体与中央区域使用本图裁切建立模板，结果属于同来源校准。转换图例测试不代表跨户型、跨画法准确率；不按图片文件名、哈希或固定位置直接回填目标。中央区域的自动框为矩形，不代表池岸等精确轮廓。底图无比例尺校准，所有坐标仍为像素。
