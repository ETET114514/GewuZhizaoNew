# 门两侧独立空间与吊顶分区：可行性分析

2026-10-14。仅分析，未改分区/吊顶算法或户型几何。分析输入是当前方案保存副本 `20261014-203817-f33e1d`，含用户新增 C004 灯具和 220 cm 入户门。

## 结论

以墙、固定通高隔断和门洞为边界，封住门洞后求连通区域，可作为独立房间顶面的自动默认范围。普通室内门两侧应检查是否分别落入两个有效空间；开门/关门的姿态不应改变空间划分。入户门也必须在分析时封口，外侧标记为室外并排除，不生成室外房间。窗洞同样需要补齐外边界。

一扇门不一定增加一个空间：如果存在其他绕行路径，门两侧仍可能属于同一连通区域。这时应提示检查漏墙、真实敞口或回路，不能在缺少边界证据时强制画一条任意分割线。家具、低柜和普通低矮隔断不应默认切断吊顶；开放客餐厅也可能需要人工分成多个吊顶设计区。房间空间与吊顶设计分区宜保持一对多。

## 当前代码与只读计算

`partition_rooms.py` 已以实墙和门窗虚拟封口做四邻接连通分量，使用坐标压缩保留细小裂缝，排除连接图边缘的室外区域。当前 15 处门窗全部参与封口，无跳过或待确认封口；当前无手绘房间覆盖。调用现有算法重新计算仍得到 3 区：

| 区域 | 当前面积 | 说明 |
| --- | --- | --- |
| R001 | 57.63 m² | 大块连通区域，多个用途被合并 |
| R002 | 2.53 m² | 上方中间的小区域 |
| R003 | 15.26 m² | 下方右侧连通区域 |

沿门洞中点法线，在分析封口两边各偏移 1 px 查询区域；另在内存副本中移除单扇门的分析封口，调用现有算法复算。未写回项目：

| 门 | 当前两侧区域 | 移除该封口后的区域总数 | 含义 |
| --- | --- | --- | --- |
| O001 入户门 | 未形成室内区 / R001 | 2 | 封口用于隔开室内与室外 |
| O005 | R002 / R001 | 2 | 当前已起到两个空间的分界作用 |
| O006 | R001 / 未形成室内区 | 2 | 右侧未闭合，去掉封口使 R001 也泄漏到室外 |
| O008 | R001 / R003 | 2 | 当前已起到两个空间的分界作用 |
| O009 | R003 / 未形成室内区 | 2 | 右侧未闭合，去掉封口使 R003 也泄漏到室外 |
| O010 | R001 / R001 | 3 | 门外另有连通路径，单独封门不能隔开 |

“未形成室内区”不是自动判定那边真实是室外；对于 O006/O009，原图中可见围护空间，但当前二维墙体闭合结果缺失。

`ceiling-geometry.mjs` 则另外从三维墙顶、洞口过梁与转角修正后的边界补默认顶面，当前得到 2 个额外顶面：上方右侧约 10.70 m²、右侧中部约 3.92 m²。这两块没有相应可选 R 区。因此编辑器显示 3 个房间，预览又显示 2 个额外顶面，两套轮廓来源不一致，是当前分割难理解的直接原因之一。

闭合诊断另提示四处候选缺口，涉及 W012/W015、W004/W009、W006/W010、W014/W016，长度分别约 53、55、72、90.5 px。它们只是几何候选，可能包括真实通道；不能全部自动补成墙。原图下方中间卧室与 O010 的围护关系也需单独核对。

## 建议的后续方案（未实现）

1. 统一二维房间分析和三维顶面的结构边界；先校核断墙、窗角回折、洞口端部，保留真实敞口。
2. 将有效门洞在分区分析中封住，计算空间连通区；独立标识室外，保持门扇开合不影响分区。
3. 对每扇室内门记录“两侧空间”：两侧不同为正常；同区提示存在绕通；缺一侧提示边界泄漏。固定通高玻璃隔断等需显式构件语义。
4. 每个空间默认生成独立天花板，内部允许多个局部吊顶/跌级；开放空间允许人工划吊顶设计区。新增空间应在同一个编辑列表中可见，避免只能预览不能编辑的额外顶面。
5. 重分区先预览并对照现有 C001～C004 的归属：灯具按位置、顶面按轮廓交集做候选迁移，歧义提示校核；不丢失已有设计。

计算本身可沿用现有实现；真正需要解决的是边界完整性、两侧关系校核和顶面归属一致性。空间数量不应从门数量机械推算，也不应先靠加大裂缝容差掩盖漏墙。

## 区域联通对照实验（同日补充）

针对“除入户门外，门两侧应为独立吊顶空间”的提议，新增可复现的离线对照。输入仍为上面的保存副本，未写回项目，未修改正式算法。每扇门均按其分析封口矩形中点，在矩形两侧各偏移 1 px 查询所属区域。

| 分析边界 | 连通区域数 | 单次分区耗时 | 门两侧结果 |
| --- | --- | --- | --- |
| 原二维实墙 + 门窗封口 | 3 | 49.62 ms | O006、O009 缺一侧；O010 两侧同区 |
| 三维墙顶足迹 + 门窗封口 | 4 | 6.00 ms | O006、O009 两侧分开；O005 缺一侧；O010 两侧同区 |
| 原二维边界与三维墙顶足迹并集 + 门窗封口 | 5 | 10.38 ms | O005、O006、O008、O009 均连接两个不同区域；O010 两侧同区 |

三维墙顶足迹取默认模型墙高处的墙体盒体，包括过梁和模型修补。坐标统一回图像像素，保留四邻接与细裂缝规则。三个对照使用同一个原墙厚中位数过滤小区域，避免改变过滤阈值影响比较。耗时仅为本机单次分区调用，不包含模型构建、启动和文件读写，不能当成稳定性能基准。

这说明连通分量计算可用，边界来源不一致确实影响结果。仅替换成三维墙顶也会丢掉原先 O005 后的闭合空间；临时并集只是定位问题的实验，不是已经验证的最终边界规则，也不能把这 5 区视为完整正确的房间答案。O010 在三组对照中都存在绕通，需要核对该门后围合，区分漏墙和真实通道。

产品规则建议表述为：**封住有效门窗洞口后，每个由墙体、明确的通高隔断围合且与室外隔开的连通空间，默认成为一个独立、可编辑的天花板区域。** 普通内部门两侧应为不同空间，作为校核条件；发现同区或缺一侧时标出问题位置。入户门仍参与封口，仅排除室外侧；开合姿态不影响空间。一个空间可设置多块局部吊顶，开放客餐厅可人工增加设计分界。低柜、普通家具不作为自动封闭边界。
