# 按门洞分割区域核查（2026-09-28）

识别后点击右侧“分割区域”。实墙参与边界，已识别且两端有支撑的门、窗只在区域分析中临时封闭；不修改 `walls`、`solid_wall_segments` 或三维洞口。家具不参与切分。未确认类型边界、悬空门窗不用于封闭。

算法以墙与门窗边界坐标构造不等距网格，再找四向连通空间；任何连到图像边缘的空间都排除，细小墙缝不会因像素取整而被自动封上。输出精确网格边界环（支持内部柱/墙形成的孔洞），过滤过小墙腔。R 编号每次按结果重建，只是候选编号，不是稳定的房间名称。

`default.png`、`dense.png`、`pale.png` 显示彩色区域和紫色虚拟分界；对应 JSON 与 `metrics.json` 保存结果。输入为前次 `output/connections-v1/` 的修复后几何，不是新一轮识别。运行 `python evaluate_rooms.py` 可复现。

密集图仍有未补全墙角、外围边界和缺少墙端的洞口，因此本轮没有强制输出房间。浅色图上方一些空间因漏门仍合并为一个候选区域；中央开放区域和左侧外围未完整分出。闭合区域也可能由错误墙段形成，需要人工校核，不把区域数量当准确率。

区域支持图层切换、列表定位、撤销、随项目保存及墙体/门窗编辑后重算。保存新增 `regions.json`，不会改变原实墙导出。尚不提供房间用途、面积、实际墙长或分房间三维地板。
