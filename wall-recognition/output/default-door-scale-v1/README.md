# 默认普通门比例估算

2026-10-12：按用户要求，把原来手动点击的普通门洞 80 cm 估算改为默认流程。

识别完成、打开未标定项目、首次把待定边界确认为门时，若没有比例且有合适普通门，自动按 800 mm ÷ 门洞像素宽设置全图比例。优先选两侧有室内区域的门，再考虑未能判明内外的门；同等候选取接近候选宽度中位数的门，选择稳定且记录参考编号、端点和假定宽度。

大入户门、待确认/已排除门、不在连续墙上的门、过短候选，以及已有明确其他物理宽度的门跳过。只有单侧闭合空间的外围候选，不在没有实际 800 mm 尺寸依据时自动选用。没有合适门时保持未标定，可以人工指定参考门或拉线/墙厚标定。该比例依赖参考门实际宽 80 cm 的假定。
