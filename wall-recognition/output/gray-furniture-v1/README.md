来源：`input/furniture-references/06.jpg`，1179 × 1366，与用户本地的 322 号图片像素一致。

- `overlay.png`：23 件家具与设施候选；`furniture.json` 保存框、类别和来源证据。
- 八个新增校准目标均匹配：左下衣柜、餐桌、三段厨房柜台、水槽、灶台、冰箱。餐桌仅框桌面，柜台与设施各有独立框。
- `transformed.png`：移位、旋转、镜像、缩放测试的输入图。八个目标均通过匹配测试。
- 最终 56 项单元/回归测试通过，耗时 132.14 秒；运行命令：`python -m unittest discover -s . -p "test_*.py" -v`。
- 实际页面已重跑，25 段实墙、7 处洞口、23 件家具与设施，耗时 24.6 秒（与测试并行时）。冰箱选择框显示正确，原有结构与编辑流程回归通过。

灰底自适应处理恢复模型输出；新增模板是既有 06 图例的画法校准，不是独立准确率测试。餐椅、餐边柜及卫浴仍有漏检；F002 等小物件有类别歧义，不能把 23 件视为完整或全正确清单。所有候选保持待校核。

复现模板匹配部分：`python recognize_furniture.py input/furniture-references/06.jpg --output output/gray-furniture-recheck`。完整模型与模板合并结果可在页面载入家具示例图后运行识别。
