# 浅色家具图核查（2026-09-15）

本次处理用户反馈的浅色渲染户型图，源文件为 `input/furniture-references/11-light-rendered.png`（1552 × 1372）。它来自 `微信图片_20260913184249_395_7.png`，现已作为 14 个显式模板的来源。以下是来源校准和变换回归，不是独立泛化准确率，也不是全图家具完整清单。

14 件包括 3 张床、3 处曲线沙发、1 张餐桌、1 张长桌、1 把座椅、4 处柜体和 1 个浴缸。选定目标与输出框的交并比约 0.94–0.99。餐桌框只包含桌面，曲线沙发方向留空，所有自动结果仍待校核。餐椅、其他座椅、茶几、其他柜子和部分小型厨卫设施仍未覆盖。

`before.json` 和 `after.json` 为家具流程前后结果，`after.png` 为最终家具叠加图；页面完整识别为 49 段实墙、8 处洞口和 14 件家具，约 28.5 秒。单独家具流程记录约 20.2 秒到 27.3 秒，耗时受机器负载影响。

## 改动与限制

增加保留浅灰线条连续强度的 `soft_contrast` 模板特征；旧模板保持原二值特征。新增模板仍在整图搜索位置、尺度、正交旋转和镜像，没有按文件名或固定坐标输出。没有更换模型权重，区域识别仍为离线实验。

模型反色、对比度等探索曾把曲线沙发认作桌子，未接入主流程；中间探测文件仅保留在本地。本次提交包含最终结果和核查记录。

## 验证和复现

在 `wall-recognition` 目录执行：

```powershell
python -m unittest discover -s . -p "test_*.py" -v
python recognize_furniture.py input/furniture-references/11-light-rendered.png --output output/pale-furniture-recheck
```

全部 60 项测试通过（约 195 秒，日志 `tests-final.txt`）。新增测试检查 14 个目标、6 件移位/旋转/镜像/缩放/变淡符号，以及实际窗框、电梯框、地毯、尺寸线裁切上的误报。变换测试与负例同样来自该来源，不能替代新的户型样本。命令行识别仅运行模板；页面会合并已有 ONNX 家具流程。
