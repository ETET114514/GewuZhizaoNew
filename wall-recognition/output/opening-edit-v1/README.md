核查日期：2026-10-10。新版服务器 http://127.0.0.1:8776/；旧 8774 / 8775 会话保留，不刷新用户的未保存编辑。

## 操作

- 点选二维门窗或门窗列表，右侧按 cm 填洞口宽、高、离地高度，以及中心距连续墙段起点。未标定时禁用尺寸编辑，待定边界需先确认为门窗。
- 输入预览，应用计一次修改；落地玻璃预设将窗台设为 0、洞高设为当前墙高，确认预览后应用。门洞离地固定为 0。
- 二维拖动实时预览，仅沿所属墙轴移动；墙段端部限制位置，不跨断墙，也不重叠其他门窗。松手应用一次，单击不修改，Esc 或指针取消恢复。
- 单件尺寸覆盖全局预设，旧位置补墙、新位置扣墙，三维同步；共享撤销、保存重开。降低全局墙高不能穿过已设置的门窗顶部。
- 重新标定保留原图门窗坐标，宽度随参考比例重算。已有房间轮廓和材质保留；门窗平面几何改变时提示核对边界，不擅自抹掉人工房间。
