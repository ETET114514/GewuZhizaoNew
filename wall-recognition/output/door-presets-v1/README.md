# 入户、卧室与卫生间门预设

2026-10-12，按用户图片和后续确认：

| 门型 | 门洞宽 | 左右门套 | 简化模型净宽 |
| --- | ---: | ---: | ---: |
| 入户门 | 1200 mm | 各 50 mm | 1100 mm |
| 卧室门 | 900 mm | 各 50 mm | 800 mm |
| 卫生间门 | 800 mm | 各 50 mm | 700 mm |

入户原范围为 1000～1200 mm，用户确认默认取 1200 mm。所有宽度可继续自定义。

“画户型 → 户型校核 → 新增门”提供门洞预设下拉框，新门默认卧室 90 cm；选择入户/卫生间会分别填入 120/80 cm。选择已有门后，右侧提供三个预设按钮；点击先预览，应用后更新洞口，可撤销和保存重开。门型由用户手动选择，不根据房间名称自动改已有门。

全局默认门洞预设改为 900 mm，门扇预设仍为 800 mm；已保存的全局与单件宽度保留。窗宽预设及窗框尺寸保持原计算。左右门套在二维开启标记与三维共用计算，每侧 50 mm；这三个预设的单件门扇恰为洞口减 100 mm，不再额外扣除之前的两侧 3 mm 示意缝。极窄的墙端裁切仍限制框宽，避免无效几何。上部门框高度沿用既有模型，不额外推定施工参数。

80 cm 门洞比例尺继续按“所选门洞确实宽 800 mm”的假定估算全图，页面已提醒不要把该假定直接用于卧室或入户门。

28 项相关 Python 测试、67 项全量 Node 测试通过。新增测试覆盖三种宽度、两种墙方向、多种比例、50 mm 侧框及二维/三维门扇一致。实际浏览器覆盖新增下拉框、已有门三按钮、应用/保存重开/撤销，以及原新增门窗、吸附、三维拖动和窄屏回归；见 `browser-check.json`。截图为各预设按钮预览及三维场景。
