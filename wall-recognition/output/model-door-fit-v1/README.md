# 三维门扇宽度修正（2026-09-21）

原先按图换算的门洞宽度会随比例变化，但门扇仍以 `door_width_mm`（默认 800 mm）为上限并贴着一侧门框，造成宽门洞旁明显留空。

修正后的按图模式让门扇适配实际门框内宽，左右各留约 3 mm 示意缝隙。预设模式保留指定门扇宽度并居中；门洞被墙段裁切或过窄时，门扇按实际可用内宽收缩。没有改变二维门洞识别位置、原始像素几何或全图比例。宽度预设输入框仅在预设模式启用。

例如 1800 mm 门洞、两侧各 40 mm 示意框：按图模式生成 1714 mm 门扇，而非截成 800 mm。仍是简化闭合门示意，尚未按洞口自动拆分双扇门。

本次验证：8 项 Node 几何测试通过，覆盖横竖门、不同标定比例、预设宽度、裁切后适配及原有门窗扣墙；Edge 浏览器检查通过，包含宽度模式控件、改色、保存、撤销、无效高度提示、二维修改后三维同步及手机布局。未修改后端识别逻辑，未重复执行完整 Python 识别回归。
