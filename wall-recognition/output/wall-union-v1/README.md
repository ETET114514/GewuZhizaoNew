# 三维一体墙体

日期：2026-10-13。核查方案副本：`projects/20261013-183746-c546b2`。

墙段及补角的长方体做实体并集，提取外表面，删除重叠部分和接触部分的内部面。表面采用一致的轴向法线，同一平面共享顶点；保持所有转角硬边。按精确边界压缩坐标，不以栅格采样近似形状，仅消除米制换算的浮点舍入差。

三维当前方案从 64 个独立墙体/补角长方体改为一个墙体网格，共 6008 个含法线顶点、7800 个三角形。断开的墙仍断开。二维墙体编号、原坐标和修改记录保留，后续编辑重建整体表面。门窗、玻璃和家具各自保持原模型与开合方式。

默认使用整体网格。原“墙体交接齐平”只控制收头和补角；关闭时恢复原墙体轮廓，表面仍合并。墙体颜色与淡化作用于完整网格。

## 验证

- `node --test test_*.mjs`：90 项通过。新增实体并集体积、闭合边界、外法线和内面删除、厚薄墙交接、门窗洞口与窗台过梁、真实窄缝、空墙体及门窗射线检查。
- `tools/check_wall_joints_ui.cjs`：当前方案副本，实际查看器只有一个带索引的墙体网格；墙体淡化恢复、桌面/窄屏、齐平关闭、预览取消、撤销、保存重开、源数据不变通过，无页面脚本错误。
- 本机 Node 生成当前方案整体网格约 15 ms（单次测量，仅供参考）。

复现浏览器检查：设置 `WALL_JOINT_PROJECT` 为上述保存方案的绝对路径，`WALL_JOINT_OUTPUT=output/wall-union-v1`、`WALL_UNION_COMPARE=1`，并在 `NODE_PATH` 中提供 Playwright。临时服务器与项目目录均在检查后清理。
