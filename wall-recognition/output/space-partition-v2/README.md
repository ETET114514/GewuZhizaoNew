# 按门两侧连通空间划分顶面

2026-10-14。正式算法为 `wall-door-regions-v2`。

## 已实现行为

- 有效门窗临时封口，再求四邻接连通分量；图外连通区排除。入户门仍封口，但外侧不生成房间；门扇开合不影响空间划分。
- 保留原二维实墙边界；只补已经相接墙体的厚度带转角，以及满足外围窗、窄自动回折、较长较厚主墙与生成宿主等共同证据的窗端连接。原墙坐标不修改，真实断缝、未确认门窗和未定洞口受保护，家具不作为边界。
- 分区后的二维房间、天花板、吊顶编辑器共用区域轮廓；停止追加没有可编辑区域归属的三维补顶。未分区时保留默认结构顶面预览。
- 在自动物理空间上查询门两侧，区分相邻独立空间、同区绕通、一侧漏闭合、封口未接两端、入户门内外歧义；手工设计切分不冒充结构闭合证据。二维“房间与地面”提供问题门定位，顶面编辑器同步显示校核提示。
- 重分区通过双向轮廓重合至少 95% 且唯一匹配迁移房间顶面设置、整房吊顶和地面属性。真正切分时，根安装面的灯具按唯一包含其位置的区域迁移，局部吊顶按完整轮廓归属迁移。依附吊顶的灯具和灯槽只有在宿主归属一致时一起迁移；跨区整房设计等歧义保留原始组件，提示重新指定。组件编号及尺寸/灯光设置保留。
- 墙体/门窗编辑重分区与墙角齐平设置变更接入上述迁移；显式重新分割区域保持一次撤销，保存重开保留区域和设计。
