# 顶面房间定位与灯具可见性（2026-10-14）

用户反馈：找不到新灯具，不知道 R001 对应哪里。

当前方案 C003 原来挂在 280 cm 原顶，灯底 272 cm；同位置的整房吊顶 C001 底面为 260 cm，灯具被吊顶遮挡。R001 是左侧连通分区，尚未命名，不能直接视为某个语义房间。

本次改动：
- 顶面编辑器增加原图定位小图、选中区域紫色轮廓、房间编号与面积，黄色点表示实际灯具；点击区域或灯具可选择。未命名区域在列表显示图上方位。
- 独立“＋ 添加灯具”入口与实际灯型名称；新增灯具按初始中心选择覆盖该点的最低顶面，考虑轮廓孔洞和所属区域。已有安装面保留。
- 被下方吊顶遮挡时提示标高与遮挡组件，可一键预览改装，仍需应用，支持取消。
- 二维定位房间、当前房间仰视、查看单灯；单灯视角对准实际位置，紫色轮廓标明灯本体，字幕显示区域和灯具编号。相机位于下方，避免从外墙视角寻找。
- 三维增加 ACES 色调映射与单灯侧向微偏移，保留白色灯体与顶面的可辨边缘。该变化影响三维预览明暗，不改变几何、颜色设置或灯光参数。
