# 家具吸附与手动新增门窗核查

日期：2026-10-12。

## 使用

- **吸附**：找素材中的“家具吸附与对齐”默认开启。移动、复制、拖入或点选放置家具时，对齐实墙面、其他家具边缘及中心；二维显示橙色对齐线、蓝色间距线与数字。按住 Alt 临时关闭，或取消勾选开关。未标定的已有家具移动/复制显示 px，标定后显示 cm。三维拖动也共用此开关与 Alt，右侧显示吸附状态和最近间距。
- **新增门窗**：先标定比例，再进入画户型 → 户型校核，点击“新增门”或“新增窗”，输入洞口宽、高及窗台（cm）。移动到墙上预览，点击放置；Esc、取消按钮、失焦或切换工具取消。提交后可从右侧继续修改尺寸、位置和开启设置。

默认宽度继承当前全局门洞/窗宽预设，未设置时 80 cm；门高 210 cm、窗高 150 cm、窗台 90 cm，均可改。门洞限制在连续墙段内，拒绝与现有有效门窗重叠、超宽、非法尺寸及超出墙高的洞口。墙体和门窗几何共用现有二维扣洞口与三维模型流程。

每次放置或拖动只提交一次，沿用共享撤销与保存重开。预览不改变文档，提交失败不新增门窗或历史。已有房间轮廓与地面材质保留，门窗新增后标记边界需要校核。

- 完整 Python 回归通过：165 项，耗时约 356 秒；随后新增门窗 4 项独立复核通过。

- `tools/check_snap_opening_add_ui.cjs`：真实浏览器鼠标手势核查对齐线、提交、Alt/开关绕过、单次撤销、门预览/Esc、重叠拒绝、窗尺寸、网络失败恢复、三维显示、三维拖动间距/取消/提交/撤销、保存重开和 390 px 窄屏，无页面脚本错误。详见 `browser-check.json`。

## 首版范围

吸附阈值二维为屏幕 8 px，三维为 80 mm；旋转家具使用在底图横纵轴上的投影包围框，仍保护原校核框与旋转占地的底图边界。仅对已有横/竖实墙面与家具进行吸附；洞口中没有实墙的部位不作为贴墙面。间距是投影重叠时最近边缘的参考距离，不进行碰撞阻止或通道规范判定。新增门窗需要已有墙段及标定比例；斜墙、弧墙、多选、成组、自由离墙门窗仍未接入。
