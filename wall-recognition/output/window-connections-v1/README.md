# 转角窗连接

日期：2026-10-13。核查源方案：`projects/20261013-183746-c546b2`，浏览器使用临时项目副本。

原来的两扇直角窗分别生成端框，转角处留有缺块、重复框，部分玻璃伸入另一侧端框。现在同窗台、同窗高且实际相接的窗口共用一根固定转角框，上下横框连接到它；固定框体做实体并集，去掉内部面和拼接缝。固定玻璃与活动窗扇分别按该框的净空收齐，避免玻璃穿框。转角框深度沿用相接墙的厚度带交集。

二维开合标记与三维采用同一净空宽度、位置和转轴。宽度开合预设仍依据原洞口实际宽度，转角框始终固定，每扇窗独立开关。原始洞口尺寸和位置不变；窗扇净宽按转角框调整。旧项目未配置开合的窗第一次打开时，仍沿用原有流程从固定玻璃示意转为可开窗扇。

## 范围与验证

仅连接明确的单段直角窗，要求窗台/窗高一致、两端深度带实际相接且无实墙隔柱。真实断缝、未定缺口、待确认/排除窗、第三处重叠洞口、不同高度、过短窗及歧义端点不连接。独立窗的既有净宽保持原规则，门框和门扇不参与合并。

- `node --test test_*.mjs`：96 项通过。新增共用框、玻璃不穿框、墙体上下墙保留、横纵/镜像/比例、双端转角、两轴/两侧独立开合、二维三维净宽一致及各类保护反例。
- `tools/check_window_connections_ui.cjs`：临时服务器和项目，当前三处连接、固定框整体网格、淡化恢复、两扇独立打开/关闭、固定转角框与墙体不变、撤销、保存重开、窄屏及源尺寸不变通过，无页面脚本错误。

复现：在 `NODE_PATH` 中提供 Playwright，运行 `node tools/check_window_connections_ui.cjs`；可用 `WINDOW_CONNECTION_PROJECT` 指定本方案目录的绝对路径。临时服务器和项目检查后清理。
