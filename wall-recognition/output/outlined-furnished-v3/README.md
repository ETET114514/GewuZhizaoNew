## 方法

旧密集图分支要求深色边缘，并依赖实心墙作为连接和厚度依据。这张图的墙内部为空白，而地毯、衣柜纹理产生了少量实心候选，导致真正的双线墙被过滤。

新增补检在图面存在足够长、跨越较大范围、同时包含水平和垂直方向的空心墙带时启用。依据这些墙带估计宽度，结合连续双边、内部空白和连接关系筛选；外部背景邻接补充短外墙。交接处只能沿有像素支撑的两侧边缘继续，不能跨过空白门洞。合并重叠候选后沿用门窗与实墙整理流程。没有按房间类别或文件名输出墙体。

## 验证与限制

完整 63 项测试通过，日志见 `tests-final.txt`。新增测试验证来源检查点、90/180/270 度旋转与缩放，以及家具裁切不能单独形成建筑墙网；原六张参考图检查点回归通过。

在 `wall-recognition` 目录复现：

```powershell
python -m unittest test_dense_outlined_walls test_outlined_walls -v
python -m unittest discover -s . -p "test_*.py" -v
```

来源图用于规则开发，旋转与缩放仍属于同来源变换检查，不能当作独立数据集评测。几个短墙角、厨房局部边界仍有漏检；原实心分支把地毯边缘和衣柜纹理当墙的误报仍存在。洞口分类和边界长度也需校核。所有自动结果均为候选。
