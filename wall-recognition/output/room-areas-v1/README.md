# 房间面积与分类工具栏核查

日期：2026-09-30。

## 计算与展示

- 使用有效地面多边形的外环面积减去孔洞面积，多块合并区域求和；按 `(mm/px / 1000)²` 换算 m²。
- 区域最终轮廓已扣除实墙，避免再次扣墙；家具不扣除，门槛按当前分区虚拟边界归属。柱体只有成为轮廓孔洞或墙体时才扣除，不推测未建模柱体。
- 列表、选中区域详情和画布显示面积；测量分类可切换图上面积标注。面积标注位于构件图层之上，避免被家具盖住。
- 合计仅代表已划区域的参考地面面积；未标定或无有效区域显示 `—`，不表示整户建筑面积。自动分区不完整时需补画或校核，未闭合且连通外部的空间不会自动生成面积。
- 由项目保存的比例和有效轮廓实时派生，未增加重复持久化面积字段；恢复旧项目即可计算。

## 工具入口

- 项目：导入、恢复、示例。
- 识别与修复：自动识别、墙体连接、墙色设置。
- 编辑与分区：选择/补墙、补家具、自动分区、手绘区域。
- 测量：拉线标定、备选墙厚估算、墙长/拐角开关、面积开关。
- 显示与三维：二维图层、三维预览。
- 保存和撤销常驻顶部；右侧为对象属性与区域编辑。分类支持方向键、Home/End，窄屏可滚动切换并换行显示控件。

## 已验证

1. `node --test test_room_areas.mjs test_wall_lengths.mjs test_floor_geometry.mjs test_model_geometry.mjs`：25 项通过，包括 6 项新增面积测试。覆盖凹形、孔洞、多块区域、缺失/非法比例、缩放平方、闭环坐标、只读输入、显示精度，并与实际地板三角网格面积比对。
2. `.venv\Scripts\python.exe -m unittest test_web test_projects test_rooms test_room_editing test_model_settings`：33 项通过。
3. 浏览器恢复 `20260928-203527-dffdd2`：R001 为 3.09 m²；独立用 Shapely 对保存轮廓核算为 7724 px² × 0.02² = 3.0896 m²。
4. 比例由 20 改为 10 mm/px，面积显示 0.77 m²，撤销恢复 3.09 m²。排除区域后合计为 `—`、标注清空，撤销恢复。
5. 恢复未标定项目并从新工具栏分区：区域列表显示“未标定”、合计 `—`，没有实际面积标注。恢复已标定旧项目后重新出现 3.09 m²。
6. 面积开关切换后标注数量从 1 变 0 再恢复；墙长及分段开关仍有效；新三维入口可打开模型。
7. 390 × 844 窄屏核查：页面无横向溢出，工具栏分组换行、内部可滚动，键盘可切换至最右侧分类；测试后恢复默认视口。
