## 已验证

- 门默认向房内开 90°，窗默认向外侧开 45°。外墙有唯一闭合室内侧时自动判断；内部门两侧均有房间时提示指定归属，未确认前快捷打开跳过。明确选择房间后门向该房内、窗向该房外；手动选择可覆盖。
- 内外分析独立于地面排除和材质。结构区域包含凹形及孔洞，按门窗两侧采样，不把未铺地当成室外。只读上下文接口不改文档或历史。
- 门可选择两侧竖轴、编辑沿扇宽的 0～100% 轴位；窗默认竖轴侧开，可改上轴/下轴横向翻转，轴位沿高度底到顶。转轴端按钮选择和轴位输入同步。
- 数学检查验证横/竖墙、左右/上下轴、内置轴及两侧方向：轴线上点固定，整扇刚体尺寸保持；五个窗扇框/玻璃部件共享旋转，墙体及洞口未改。
- 二维侧开弧线与门窗线、上下翻转投影及轴线预览正确；三维整扇转动。三维“调整方向与转轴”返回对应二维属性。
- 自动方向、归属、转轴及位置可以保存重开、一次撤销；尺寸编辑保持参数并复核归属。非法轴位和请求失败不改变权威文档；取消恢复原设置。
- 390 × 844 px 窄屏操作通过，无横向溢出；未实测物理触屏。正常操作无脚本错误。原方向编辑及五按钮使用新角度契约的浏览器回归通过。

## 边界

没有房间用途的可靠语义，不自动把两个房间之一指定成门所属房间；缺墙、未闭合、双侧室内的阳台/庭院等情况需归属或手动校核。内置轴可能使扇跨越两侧，只是几何示意。固定玻璃继续跳过；无碰撞、净距、真实五金、双扇或移门模拟。加载旧项目不改写其数据，自动方向在应用或快捷打开时重新确定；新手动设置保留。
