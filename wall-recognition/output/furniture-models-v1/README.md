# P11：程序化家具细节与逐件三维编辑

日期：2026-10-01。

## 使用

1. 打开已标定的项目，在“显示与三维”里打开三维。
2. 点击可见家具或使用右侧列表选择对象；“定位家具”自动淡化墙体，便于查看遮挡后的家具。
3. 输入中心 X/Y、横向/纵向占地、高度、离地、整体旋转或主体颜色，画面即时预览。
4. 应用后二维同步，可撤销并保存；未应用草稿可放弃。默认外观重置高度、离地、旋转、颜色，保留当前占地和位置，仍需应用。

## 模型与坐标约定

- 17 类：床、沙发、椅子、桌子、餐桌、茶几、柜子、鞋柜、电视柜、厨房柜台、水槽、灶台、冰箱、浴室柜、马桶、浴缸、淋浴间。床具、坐垫、扶手、柜门、把手、桌腿、水槽、灶圈、卫浴及淋浴隔断由本地几何生成，无新增网络模型依赖。
- 待定家具、洗浴区待确认、区域待确认及水景保持待校核，不猜测三维类别。
- X 向右、Y 向下，以原图左上角为原点。位置和占地写回同一份 `bbox_px`，实际 mm 按当前比例换算。旋转为相对原框和原有床头/靠背朝向的顺时针附加角度。
- `model_3d` 保存高度、离地、附加旋转和主体颜色。重新标定会改变水平占地实际尺寸，已设定的竖向 mm 保持；原始无该字段项目使用类别默认值。
- 前后端校验范围、有限数值、图片边界与旋转后边界。无比例时不可按实际尺寸编辑；无效请求不写入历史或改变项目。
- 修改预览只存在页面，应用才改变项目；保存、关闭和对象切换保护未应用草稿。

## 当前边界

本轮完成参数化结构示意与数值摆放，不含商品模型导入、写实贴图或拖拽操纵杆；不会自动吸附墙面或检查家具相互碰撞。灶具/水槽等嵌套设施为独立对象，移动柜台不会自动带动其他设施。主体颜色不覆盖床品、玻璃和五金的细节配色。家具平面尺寸仍取决于识别框与比例，需要人工校核。
