# 相接墙角凹槽补齐

日期：2026-10-13。核查方案副本：`projects/20261013-183746-c546b2`。

原规则会收掉短凸头，但横纵墙厚不同或端点停在中心时，墙面外角仍缺一小块。新规则补齐实际相接墙的局部厚度带交集；扣除已有墙体、门窗及未定洞口，并避免重复补块。两侧洞口同时经过转角时不建通高墙柱，转角窗只补窗下和窗上。真实断缝不补接。

沿用“墙体交接齐平（默认）”，关闭后恢复原三维墙段；不修改二维源墙、家具、房间、比例、门窗尺寸及开合参数。
