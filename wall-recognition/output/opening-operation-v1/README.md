# 门窗开启方式与方向核查

核查日期：2026-10-12。使用临时目录和随机端口的隔离服务器，自建 400 × 300 px 户型含垂直门和水平窗；不修改用户项目与现有 8765 服务。

## 已验证

- 门可选择两个铰链端、两侧开向及 0～90°；窗可选固定玻璃或单扇平开。方向以底图轴为准，横墙显示左/右铰链、上/下开向，竖墙显示上/下铰链、左/右开向。
- 二维扇线/弧线/铰链点即时预览，取消或 Esc 恢复；应用一次计一条修改记录，可一次撤销。
- 三维门扇绕同一铰链转动；平开窗的活动框和玻璃一起转动，所属墙体和固定框保持位置。旧项目未设置时，关闭门/固定窗模型保持原样。
- 单独修改开向不改变像素洞口、实墙、比例、房间轮廓、面积口径或材质。未标定时尺寸字段禁用，开向仍可设置。
- 调整窗宽保留开启设置；数学/API 检查还覆盖移动及重新标定。开向写入 walls.json，保存打开后恢复；重新确认不同门窗类别会清除原开启方式。
- 模拟提交失败：文档及历史不变，可取消预览恢复原设置。固定窗预览可取消并恢复原平开角度。
- 390 × 844 px 窄屏操作通过，无横向溢出；正常操作无页面脚本错误。本次窄屏为鼠标/键盘核查，未实测物理触屏设备。
- 家具复制浏览器回归通过，包括二维/三维入口、取消、失败恢复、撤销及保存重开。

## 边界

门为单扇平开示意；窗为固定或单扇侧开。不开启真实门窗机械仿真，不自动判断内开/外开，也不自动采用识别候选的铰链/开向；开启扇可伸出底图，不做对象碰撞检查。移门、双扇门窗、上悬窗及真实框型/材质待做。尺寸编辑仍限于所属连续墙段；原三维的洞口裁切和墙体校核提示继续适用。
