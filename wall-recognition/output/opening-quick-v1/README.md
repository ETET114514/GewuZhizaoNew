# 快捷打开门窗核查

核查日期：2026-10-12。临时项目目录、随机端口隔离服务器；自建两扇门、未设窗型窗及固定玻璃窗的户型，保留用户现有服务和项目。

## 已验证

- 二维“空间预览”下方及三维右侧上方常驻五按钮：打开门、打开窗、打开所有门、打开所有窗、打开所有门窗。
- 单件先选择目标：门/窗按钮仅启用对应类别；可以点二维构件，或使用快捷区下拉列表，三维下拉选择保持独立。
- 所有范围按钮只修改相应对象；一键开到 90°，保留已有铰链端、开启侧、洞口、墙体、比例和房间数据。
- 未设窗型的窗按单扇平开示意打开；已明确设置固定玻璃的窗跳过，反馈数量。已排除/需确认的待定门窗不参与。
- 一次批量计一条修改记录，一次撤销恢复全部对象；重复点击全开对象不增加历史。保存打开恢复整批开启状态。
- 提交失败后文档、历史不变，按钮恢复可用。存在未应用修改时，快捷按钮禁用，避免丢失预览。
- 390 × 844 px 窄屏能操作批量打开，无页面横向溢出。此次为浏览器鼠标/键盘检查，未实测物理触屏设备。
- 原门窗方向预览、取消、尺寸调整、三维、保存重开及未标定方向的浏览器回归通过。正常操作无页面脚本错误。

## 边界

这些按钮实际保存开启状态，当前仅单扇平开示意。未知窗型转为平开是用户点击后的操作，不是自动识别结论；明确固定玻璃保持原样。没有批量关闭按钮，关闭可编辑单件 0° 或撤销。仍不做碰撞检测或室内外推断。
